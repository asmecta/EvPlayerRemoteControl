## 2024-05-18 - Prevent Renderer Freezing and Memory Leaks in DOM Video Processing
**Learning:** In an Electron/Chromium environment, concurrently processing many video files using hidden DOM `<video>` elements (e.g. within a `Promise.all` over an unbounded array of dropped files) can quickly exhaust resources and freeze the renderer thread. Furthermore, simply waiting for `onseeked` or `onerror` events is not enough for garbage collection; if the `src` attribute remains attached to the hidden `<video>` elements, Chromium retains the media resources, causing severe memory leaks on large batches.
**Action:** When extracting thumbnails or metadata using hidden `<video>` elements, always implement a concurrency limit (e.g., process 3-5 at a time). To ensure immediate resource cleanup, invoke a cleanup function that removes the `src` attribute (`video.removeAttribute('src')`) and resets the element (`video.load()`) inside both the success and error event handlers.
